## Deviations from the spec
1. **Ruff excludes `tools/`** (`exclude = ["tools"]`). `tools/phase1_probe.py` predates the formatter and the task forbids modifying `tools/`, but criterion 3 requires `ruff format --check .` to be clean; exclusion was the only compliant way to satisfy both.
2. **DB URL into Alembic**: `alembic.ini` holds a blank `sqlalchemy.url`; `migrations/env.py` sets it from `Settings` and builds the engine via `db.make_engine` (the spec's "reading the DB URL from Settings"). This also means migrations get WAL/foreign keys and the parent directory is created on demand.
3. **Ruff post-write hook + template fix**: `migrations/script.py.mako` import order corrected and a ruff hook added to `alembic.ini`, so autogenerated revisions come out formatted and lint-clean automatically.
4. **Nullable API-derived columns**: all stat columns in `matches`/`member_games` that come straight from Riot JSON are `Mapped[... | None]`. The architecture doesn't specify nullability, and Riot can omit fields (e.g. `challenges` is explicitly optional); nullable beats crashing or faking zeros. Timeline fields are nullable per spec ("None if no timeline").
5. **`MemberGameStats` carries `match_id`**: it is part of the member_games data model and T002 needs it for the unique constraint; harmless for the CLI.
6. **Two extra tests beyond the spec**: normal-match participants parse (asserting `subteam_id == 0` — Riot sends `0`, not a missing field, outside Arena) and an explicit "all three tables created" check. The duration threshold test additionally covers the boundary (`duration == 300` → valid).
